Status: pending

Status: pending

## 4. Marketplace
Status: pending
Goal: Browse available jobs with pay per hour, duration, and start time

Status: pending
Goal: Commit a node to a job up to 1 hour before start; lock at start

Status: pending
Goal: Credit earnings on job completion and show transaction history

## 7. Referral System
Status: pending
Goal: Referral codes, direct referral tracking, tier unlocks

## 8. Withdrawals
Status: pending
Goal: Referral-gated withdrawal flow using test currency
